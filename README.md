# 부경대 강의 시간표 및 개인 일정 관리 웹앱

팀 프로젝트 기획 PDF를 바탕으로 프로젝트 목적, 주요 기능과 요구사항을 정리합니다. 현재 저장소에는 기획 PDF만 있으므로 아래 내용은 구현 기준과 개발 순서입니다.

## 프로젝트 개요

부경대학교 학생이 개설 강의를 검색하고 시간표를 구성하며, 강의계획서와 개인 일정을 주간·월간 캘린더에서 확인할 수 있는 웹 애플리케이션입니다.

기존 시간표 서비스에서 부경대학교 시간표를 구성하기 어렵고 개인 일정을 함께 관리하기 불편하다는 문제를 해결하는 것을 목표로 합니다.

## 핵심 기능

- 강의명 또는 교수명으로 강의를 검색하고 요일·교과목 등의 조건으로 필터링합니다.
- 강의 시간 중복 여부를 확인하고, 선택한 강의를 시간표에 추가·삭제합니다.
- 강의계획서가 확보된 강의는 시간표에서 강의 정보를 열어 계획서 내용을 확인합니다.
- 개인 일정을 등록하고 수정·삭제하며, 주간·월간 캘린더에서 강의 일정과 함께 봅니다.
- 시간표는 학기별로 관리합니다.

### 초기 범위와 제약

기획서의 기본 범위는 부경대학교 포털과의 직접 연동 없이 강의 데이터를 수집하거나 수동 입력해 사용하는 것입니다. 외부 유료 API는 사용하지 않고 무료 호스팅·DB를 우선합니다. 실시간 푸시 알림 및 시간표 공유는 초기 범위에서 제외합니다.

## 요구사항 및 수락 기준 초안

기획서에 제시된 정성적 요구사항을 개발·검증 가능한 기준으로 구체화합니다. 실제 측정 수치와 지원 브라우저는 팀에서 확정하세요.

| 영역 | 기준 초안 | 확인 방법 |
|---|---|---|
| 강의 검색 | 강의명·교수명 검색이 정상 동작하고, 확정한 데이터 규모에서 목표 응답시간 이내에 결과를 표시한다. | 개발 데이터셋으로 검색 시나리오 실행 및 응답시간 측정 |
| 시간표 | 이미 선택된 강의와 시간이 겹치면 추가를 차단하고 충돌 이유를 표시한다. | 같은 시간대 강의 선택 및 경계 시간 테스트 |
| 일정 입력 | 필수 입력값이 누락되거나 종료 시각이 시작 시각보다 빠르면 저장하지 않고 필드별 오류를 안내한다. | 유효·무효 입력값 테스트 |
| 캘린더 | 월간·주간 보기에서 강의와 개인 일정을 구분해 표시하고 월·주 이동을 제공한다. | PC·모바일 화면 점검 |
| 데이터 보존 | 새로고침 또는 재로그인 뒤에도 저장된 사용자 데이터가 유지된다. | 저장 후 재접속 확인 |
| 권한 | 로그인 기능을 제공한다면 사용자별 시간표와 개인 일정의 조회·수정 권한을 분리한다. | 다른 사용자 데이터 접근 시도 |
| 호환성 | 팀이 정한 최신 데스크톱·모바일 브라우저에서 핵심 흐름이 동작한다. | 브라우저별 핵심 시나리오 점검 |

## 권장 개발 순서

1. 요구사항과 수락 기준을 팀에서 확정하고 강의·분반·시간표 데이터 계약을 합의합니다.
2. 앱 프레임워크와 Supabase 개발 프로젝트를 정하고 DB 마이그레이션 및 샘플 데이터를 준비합니다.
3. 정적 강의 데이터로 강의 검색, 시간 중복 확인, 시간표 CRUD를 구현합니다.
4. 주간·월간 캘린더와 개인 일정 CRUD를 구현합니다.
5. 강의계획서 수집기의 출처·권한·출력 형식을 확인하고 staging import를 구현합니다.
6. 수집 결과를 검증·적재하고 강의 상세에서 계획서를 표시합니다.
7. 권한, 모바일 레이아웃, 빈 데이터·오류 상태와 성능을 검증한 뒤 배포합니다.
